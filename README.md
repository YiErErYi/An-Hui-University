# 自动键鼠操作程序 - 增强版

## 程序说明
这是一个基于PyQt5开发的自动化键鼠操作程序，支持录制、回放和自定义工作流功能。

## 文件说明
- `AutoMouseKeyboard_Enhanced.exe` - 主程序（增强版） 
- `启动程序.bat` - 快速启动脚本

## 功能特点
1. **录制功能** - 记录鼠标点击、移动和键盘输入
2. **工作流编辑** - 创建和编辑自定义操作序列
✅ 历史记录转工作流 - 点击历史记录自动转换为工作流
✅ 工作流回放 - 自定义工作流可以正常执行
✅ 编辑后回放 - 修改工作流后能够正常回放
✅ 快捷键功能 - Del删除、Esc中断功能

## 使用方法
1. 双击 `AutoMouseKeyboard_Enhanced.exe` 或运行 `启动程序.bat`
2. 点击"开始录制"按钮开始记录操作
3. 执行需要自动化的鼠标和键盘操作
4. 点击"停止录制"结束录制
5. 点击"开始回放"重复执行录制的操作

## 工作流功能
- 点击历史记录中的任意项可将其转换为工作流进行编辑
- 支持修改操作延时、坐标等参数
- 可以保存自定义工作流为新的历史记录

## 注意事项
- 程序需要管理员权限才能正常监听键鼠事件
- 录制的操作会自动保存到 `recorded_actions_history` 目录
- 建议在使用前先测试基本功能

## 系统要求
- Windows 7/8/10/11
- 分辨率：建议1920x1080或更高

## 技术支持
如遇问题，请检查：
1. 是否以管理员权限运行
2. 防火墙是否允许程序运行
3. 是否有足够的磁盘空间保存录制文件
