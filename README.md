# 自动键鼠操作程序 - 增强版

## 项目简介

这是一个基于 **Python + PyQt5** 开发的 Windows 桌面自动化工具，中文名称为「自动键鼠操作增强版」。它能够**录制**用户的鼠标与键盘操作，并在之后**原样回放**，从而将重复性的人工操作自动化。无论是批量表单填写、重复性点击流程，还是软件测试辅助，都可以使用本程序来减轻手工操作负担。

### 适用场景

- 需要多次重复相同鼠标/键盘操作的日常任务
- 软件功能的自动化验收测试
- 课堂/实验演示的自动化脚本

---

## 功能特点

| 功能 | 说明 |
|------|------|
| **手动自动化操作** | 通过界面设置坐标、鼠标动作（移动/单击/双击/右击/拖动）、键盘文本及延迟，一键执行 |
| **录制用户操作** | 实时捕获鼠标点击、移动和键盘输入，保存为历史记录文件 |
| **回放录制操作** | 将已录制的操作序列按原顺序重新执行 |
| **自定义工作流** | 手动添加、删除、编辑操作步骤，构建个性化自动化脚本 |
| **历史记录管理** | 浏览、重命名、删除历史操作记录；一键将历史记录导入工作流进行二次编辑 |
| **快捷键支持** | `Del` 键删除历史记录，`Esc` 键随时中断录制或回放 |

## 使用方法

### 方式一：直接录制回放

1. 以**管理员权限**运行 `12_enhanced.py`（`pynput` 监听键鼠事件需要管理员权限）
2. 点击「**开始录制用户操作**」按钮，程序开始捕获所有鼠标和键盘事件
3. 执行需要自动化的操作
4. 再次点击按钮（或按 `Esc`）停止录制；录制结果将出现在「历史操作记录」列表
5. 点击「**回放录制操作**」按钮，程序将重放刚才录制的动作序列

### 方式二：自定义工作流

1. 在「自定义工作流」区域点击「**添加步骤**」，按需配置鼠标动作、坐标、键盘输入和延迟
2. 点击「**执行全部步骤**」运行工作流
3. 可点击「**保存为历史记录**」将工作流保存以备日后复用

### 方式三：编辑历史记录

1. 在「历史操作记录」列表中点击某条记录，其步骤将自动载入「自定义工作流」区域
2. 按需修改步骤内容
3. 点击「**执行全部步骤**」验证效果，或点击「**保存为历史记录**」另存为新记录

---

## 注意事项

- 程序需要以**管理员权限**运行，否则 `pynput` 无法正常监听系统级键鼠事件
- 历史记录文件保存在程序目录下的 `recorded_actions_history` 文件夹中（JSON 格式）
- 回放过程中可随时按 `Esc` 键中断
